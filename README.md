# SIC SEMPER TYRANNIS — Démo jouable

[Jouer dans le navigateur](https://neajt9a.github.io/iron-relay-demo/)

Menu principal → Nouvelle partie → cinématique L’Éveil → Les boulevards de Picrochole → intermission.

La cinématique peut être passée. La mission est un combat tactique de mechas au tour par tour, en français. Le chargement de sauvegarde n’est pas encore disponible.

Ce dépôt contient la version compilée du jeu et ses ressources publiques. GitHub Actions publie son contenu sur GitHub Pages à chaque mise à jour de `main`. Aucun serveur applicatif ni compte de jeu n’est nécessaire.

Les licences des dépendances sont conservées dans `licenses/` et `hud.js.LEGAL.txt`.
